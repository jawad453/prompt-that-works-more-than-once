# A Prompt That Works More Than Once

This repository contains my reusable prompt for extracting structured information from real job listings.

## Contents

- `final_prompt.md` — Final reusable prompt (Version 2)
- `final_submission.pdf` — Complete assignment submission
- `test_results/test_log.md` — Testing record for 15 real job listings

## Summary

The prompt was tested on 15 real job listings. One genuine prompt failure was identified during testing, the prompt was refined to address the failure, and the failed case was retested successfully.

The final prompt requires exact extraction of job titles, prevents guessing or inventing information, and returns structured data as valid JSON.
